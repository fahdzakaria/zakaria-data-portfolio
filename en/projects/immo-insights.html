Architecture

From source to site, every Monday

The pipeline rebuilds from scratch every week on GitHub Actions: nothing depends on a local machine.

01 · Bronze

Ingestion

Airflow DAG: downloads the six sources as Parquet, with retries and schema checks.

02 · Silver

Cleaning

BAN geocoding with caching, DPE and rent matching, geographic enrichment.

03 · Gold

dbt marts

Tested DuckDB models: prices, trends, yield, DPE impact, score, neighborhoods.

04 · Site

Publishing

Verified JSON export, embedded in a Next.js site with no API server, deployed on Vercel.

Technical decisions

Numbers you can verify

Reliability first

  • No price shown below 5 sales over 24 months: the area stays greyed out.
  • Median rather than mean, and figures flagged as low-confidence below 20 sales.
  • DPE impact with a confidence interval: a non-significant gap is presented as such.

Pipeline safeguards

  • dbt and pytest tests run by CI on every push.
  • The export refuses to publish if the row count drops by more than 20%.
  • Alerts on failure; publishing never replaces healthy data with broken data.

Static site, zero cost

  • The marts are exported as JSON and embedded in the site: no API server to pay for.
  • The same logic also runs behind a FastAPI API for the local version (Docker).

From department to neighborhood

  • MapLibre map: when you zoom in, large cities switch to IRIS divisions.
  • Towns and neighborhoods share the same color scale.
