IMMO ETL

A Zillow ZHVI → PostgreSQL pipeline designed to be rerun safely and to support monitoring, built before the Immo Insights N°06 platform.

  • Python
  • PostgreSQL
  • SQLAlchemy
  • Metabase
Code on GitHub README

Architecture

Four steps

01

Extraction

Reads the CSV and validates the schema.

02

Transformation

Wide → long format, monthly and yearly changes, cleaning.

03

Loading

Upsert of regions, then of monthly prices.

04

Reporting

Metabase comparison dashboards.

Technical decisions

Rerunnable without corruption

Idempotence

  • Composite primary key on (region_id, dt).
  • Loading through a temp table, then ON CONFLICT DO UPDATE.

Reliability

  • Input CSV validation (RegionID and monthly columns).
  • Unit tests and an optional database integration test.
Representative query
1SELECT dt, AVG(zhvi) AS avg_zhvi
2FROM prices_monthly
3GROUP BY dt
4ORDER BY dt;
